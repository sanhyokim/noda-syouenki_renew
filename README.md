# 野田の消煙機 JL-8A — LPリニューアル

現行LP（https://shoenki.duct-noda.com/ ）のリニューアル版です。
ライブラリやビルドは使わず、HTML / CSS / JavaScript だけで動く静的サイトです。

![PC ファーストビュー](docs/preview/pc-01-hero.jpg)

## プレビュー

リポジトリ直下でローカルサーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# または
npx serve .
```

→ http://localhost:8000/

スクリーンショットは [`docs/preview/`](docs/preview/) にあります（撮影環境に日本語Webフォントが無いため、代替フォントで表示されています。本番では下記の Google Fonts が読み込まれます）。

## デザインの考え方

「AIが作ったっぽい」「見にくい」というご意見を受けて、2回目で全面的に作り直しました。

- **色**：本体に貼られているステッカー（黄の「消」・白の「煙」・赤の「機」）から取りました。白とスチールグレーの地に、黄・赤・墨の3色だけを使います。
- **文字**：本文は読みやすさを優先して UD フォントの BIZ UDPゴシック（PC 17px・スマホ 16px）。見出しは Zen Kaku Gothic New、数字は Barlow Condensed、点検記録の手書き部分だけ Klee One を使います。
- **見出し**：英語のラベルや「01〜11」の通し番号はやめ、漢字1文字のタイル（声・電・機・効・守・例・置・金・流・問・資）と日本語の見出しにしました。
- **モチーフ**：飲食店と消煙機の現場にある物で内容を見せます。管理会社からの通知文、本体の銘板（仕様表）、畳1枚との大きさ比較、毎月の点検記録（押印つき）、設置スペースの平面図。
- **動き**：控えめにしています。動くのは、集塵の仕組みのシミュレーション、写真の番号ピン、点検記録の書き込み、スクロール時の表示だけです。3D表示はなくしました。

## 掲載情報について（取扱説明書を優先）

現行LPと取扱説明書（消煙機 JL-8A 取扱説明書）の内容をもとに作成し、両者が食い違う箇所は取扱説明書に合わせました。

| 項目 | 現行LP | リニューアル版（取扱説明書に準拠） |
|---|---|---|
| 消費電力 | 500W | **300W** |
| 電気代の目安 | 月2,500円程度 | **月1,500円程度**（300W × 1日6〜7時間 × 月25日 × 31円/kWh で再計算） |
| 除去の仕組み | meta説明文に「独自フィルター」 | **電気集塵方式**（高電圧部12kV＋低電圧部6kV） |
| フィルター交換 | 継続購入は不要 | 継続購入は不要。ただし説明書の消耗品一覧に合わせ「長期使用で劣化した部品（電極・ガイシなど）は交換が必要な場合あり」と追記 |
| 会社のメール | （記載なし） | info@noda-duct.com（説明書記載） |

説明書から新たに掲載した情報：仕様表（静圧98Pa、重量100kg、電源 単相AC100V 50/60Hz、使用環境 0〜50℃・湿度80%以下）、保証期間1年、メンテナンススペース（正面0.7m以上）、ダクト風速4〜6m/s、チャンバーボックス接続、屋外設置時の防雨カバー（別売）、扉を開けると電源が切れる安全装置、運転ランプの表示、出力電圧の正常値（12kV±2kV / 6kV±2kV）、粉塵の多い工場等では使えない旨。

## 公開前に確認・対応が必要なこと

- **フォームの送信先**：現行LPはWordPress（Elementor）のフォームです。`index.html` の `<form data-endpoint="">` に送信先URLを設定すると、FormData を POST します。未設定のあいだは「プレビューのため送信されません」と表示されます。
- **計測タグ**：現行LPの Google Tag Manager（GTM-W7PSRQTX）は入れていません。公開時に移植してください。
- **会社ドメイン**：説明書のメール・Webは `noda-duct.com`、現行LPのリンク先（会社概要・プライバシーポリシー等）は `duct-noda.com` です。リンクは現行LPのまま、メールは説明書のまま掲載しています。正しい方に揃えてください。
- **イメージ表記**：お悩みの通知文と点検記録シートは説明用のイメージです（ページ内にも「イメージです」と表記しています）。
- **OGP画像**：`assets/img/ogp.jpg` は代替フォントで書き出しています。必要に応じて差し替えてください。

## 画像

- 写真は現行LPから取得したものです（WebPに変換して軽量化）。
- 導入事例ギャラリーの小さな写真は、現行LPのサムネイル画像から写真部分を切り出したもので解像度が低めです。高解像度の元写真があれば差し替えます。

## 実装メモ

- 依存ライブラリなし。集塵シミュレーションは Canvas 2D で描いています。
- `prefers-reduced-motion` を尊重し、動きを減らす設定では表示アニメーションと点検記録の書き込みを止め、集塵シミュレーションはゆっくり動かします。
- 画面外のアニメーションは停止し、YouTube はクリックされるまで読み込みません。
- 見出しは文節ごとに `<span class="nb">` で区切り、スマホでも単語の途中で改行しないようにしています（`word-break: auto-phrase` 非対応の Safari 向け）。
