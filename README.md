# 野田の消煙機 JL-8A — LPリニューアル

現行LP（https://shoenki.duct-noda.com/ 、WordPress + Elementor）のデザインと構成をそのまま活かし、WordPress を使わない静的サイトとして作り直したものです。
ライブラリやビルドは使わず、HTML / CSS / JavaScript だけで動きます。現行サイトにはなかった「仕組み」セクション（集塵シミュレーション）を加えました。

![PC ファーストビュー](docs/preview/pc-01-hero.jpg)

## プレビュー

リポジトリ直下でローカルサーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# または
npx serve .
```

→ http://localhost:8000/

スクリーンショットは [`docs/preview/`](docs/preview/) にあります。撮影環境に日本語Webフォントが無いため代替フォントで表示されていますが、本番では Noto Sans JP（現行LPと同じ書体）が読み込まれます。

## 現行LPから変えたこと

色（紺 #15324a・オレンジのボタン・青 #3498db）、ロゴ、写真とイラスト、セクションの順番、文章は現行LPのままです。そのうえで、見にくい・使いにくいところを直しました。

**見やすさ**

- 本文を 16〜17px・行間 1.85 に揃えました（現行は 14px 前後で行間が詰まっていました）。
- 見出しは文節ごとに改行位置を決め、「放置し／ていませんか？」「対策で／きます。」のような変な位置での改行をなくしました。
- 背景に薄く出ていた本体の3Dモデルをやめ、文字の後ろは無地にしました。
- ファーストビューは、写真の上に文字が重なっていたのを、左に文字・右に写真の2段組みにしました。スマホでは写真の下に文字を置いています。
- 「POINT01〜03」の丸や導入店舗の帯は、画像に焼き込まれていた文字を本物の文字にしました。くっきり表示され、検索エンジンにも読まれます。
- ボタンの文字を濃い色にして、オレンジの上でも読みやすくしました。
- 導入実績の3項目は、数字を大きく見せるカードにしました。

**使いやすさ**

- スマホの左下に重なっていた「お電話」「LINE問合せ」の丸いボタンを、画面下の固定バー（お電話 / LINE / 無料で資料請求）に変えました。本文に重なりません。フォームを入力している間は自動で隠れます。
- 「スマホ表示で Loading 3D Model: 0%」の文字が出ていた問題もなくなりました。
- ヘッダーに「特長・仕組み・導入事例・ご利用の流れ・よくある質問」へのリンクを付けました（PC）。
- 稼働動画は、現行では白い箱だけが表示されていました。サムネイルと再生ボタンを表示し、押したときにだけ YouTube を読み込みます。
- よくある質問は開閉式のまま、「設置・工事」「費用・メンテナンス」「導入・ご契約」「製品・仕組み」の4つに分けました。PCでは左に分類の目次（読んでいる分類に印が付きます）と、電話・フォーム・LINEの問い合わせ欄を固定表示し、スマホでは分類ボタンを上に、問い合わせ欄を最後に置いています。答えには「A」を付け、開くときはなめらかに広がります（対応ブラウザのみ。動きを減らす設定では動きません）。
- 会社概要・プライバシーポリシー・お問い合わせは、別サイトへのリンクではなく、このサイトのページにしました（下記）。

## 全国販売に向けて

九州・中国地方に限らず全国で販売するため、地域が限られて見える表現を見直しました。

- 導入店舗の帯から地域名（福岡・熊本）を外し、業態だけにしました。九州以外の方が「九州限定」と受け取らないようにするためです。
- ファーストビューの帯に「全国対応」を加えました。
- よくある質問に「対応エリアはどこまでですか？」を加えました（13問）。質問には地域名を出さず、答えで「全国に対応」「九州・中国地方以外では提携業者が設置工事と毎月のメンテナンスを担当」と説明しています。
- 「ご利用の流れ」の下に、同じ内容の注記を入れました。
- 資料請求とお問い合わせのフォームに「店舗の所在地（都道府県）」を加えました。
- 説明文（meta description）と構造化データ（対応エリア：日本）に全国対応を反映しました。

## 公開の手順

1. **置き場所を決める**：Cloudflare Pages・Netlify などの静的サイト用ホスティング（無料枠あり）か、今のサーバーにファイルをそのまま置きます。リポジトリ直下（`index.html` / `company/` / `privacypolicy/` / `contact/` / `assets/` / `robots.txt` / `sitemap.xml` / `_headers`）を公開してください。`v2/` `wordpress/` `docs/` `tools/` は公開しなくてかまいません。
2. **フォームの送信先を設定する**（下記）。
3. **独自ドメイン（shoenki.duct-noda.com）を新しい置き場所に向ける**：DNS の切り替えは現行サイトが見られなくなる作業なので、切り替えのタイミングはご判断ください。URL は同じなので、検索順位はそのまま引き継がれます。

`_headers` は Cloudflare Pages / Netlify 用のキャッシュ設定です（他のサーバーでは無視されます）。

## フォームの送信先（設定が必要です）

`index.html`（資料請求）と `contact/index.html`（お問い合わせ）の `<form data-endpoint="">` に送信先のURLを入れると、その宛先に送信します。2つとも同じURLでかまいません。空のあいだは「プレビュー」として完了画面だけを表示し、実際には送信しません。

おすすめは **Google Apps Script**（無料）です。[`tools/form/google-apps-script.gs`](tools/form/google-apps-script.gs) を Google スプレッドシートに貼り付けてウェブアプリとして公開すると、次の3つを行います。設置手順はファイルの先頭に書いてあります。

1. 送信内容をスプレッドシートに1行ずつ記録（シート「資料請求」「お問い合わせ」）
2. お客様に自動返信メールを送信（資料請求はダウンロードのご案内、お問い合わせは受付確認）
3. 担当者に通知メールを送信（件名は「【野田の消煙機LP】資料請求がありました［福岡県］○○ 様」の形で、本文にも消煙機のLPのどのフォームから来たかを書きます。都道府県は地域ごとの振り分けに使えます）

通知先（`NOTIFY_TO`）は info@noda-duct.com・koroyasu@duct-noda.com・azuma@duct-noda.com・nagamizu@duct-noda.com の4件を設定済みです。お客様が自動返信メールに返信すると、先頭の info@noda-duct.com に届きます。ファイル先頭の `DOWNLOAD_URL`（資料PDFのURL）だけ書き換えてください。

送れるメールは宛先の数で数えて、Gmail（無料アカウント）は1日100件、Google Workspace は1日1,500件までです。1回の送信で、自動返信1件と通知4件の計5件を使います。Formspree などのフォームサービスを使う場合も、そのURLを `data-endpoint` に入れるだけで送れます。

## 現行サイト（WordPress）への部分移植

[`wordpress/elementor-shikumi.html`](wordpress/elementor-shikumi.html) は「仕組み」セクションだけを、現行サイトの Elementor に載せるための部品です。中身をすべて HTML ウィジェットに貼り付けると動きます。静的サイトへ移行する場合は不要です。

- 固定ヘッダーの高さ（WordPress の管理バーを含む）は自動で読み取ります。ずれる場合は `<section class="nesp" data-offset="70">` のように指定できます。
- スクロールに合わせた固定表示ができない場合は、3つの段階を自動で繰り返し再生します。
- シミュレーションの中身は `assets/js/site.js` と同じです。どちらかを直したら、もう一方も合わせてください。

## 画像

- 写真・イラスト・ロゴは現行LPから取得し、WebP に変換して軽くしました。
- お悩みの挿絵（煙が隣のマンションに届く焼肉店の街並み）は、HTMLに直接書いた SVG です。4つのお悩みと同じ番号を振っています。煙が排気口から出続けてマンションへ流れ、住人が「ゴホッ」と咳き込み、店主は手紙を手にため息をつき、洗濯物やちょうちんが揺れます（CSS アニメーション。画面に見えている間だけ動き、動きを減らす設定の端末では止まった絵になります）。以前のお悩みの人物イラストは、この挿絵に置き換えました。
- 「特長」の本体写真（`assets/img/jl8a-1000.webp` / `jl8a-600.webp`、5:4）は、2026年10月15日にご提供いただいた本体画像（パンフレットの仕様ページと同じもの）です。背景はそのまま使い、本体の上下左右が切れないよう中央に寄せて切り出しています。
- LINE のボタンには、LINE の公式アイコン（`assets/img/line-icon.webp`）を使っています。
- フッターのロゴは、現行LPと同じく青地にそのまま載せる版（`assets/img/logo-footer.webp`、下線を白にしたもの）です。
- 会社ロゴ（株式会社野田の「N」マーク、2026年10月18日にご提供）は、全ページのフッターの社名の前と、会社概要の「商号」に入れています。ページ内に直接描いているので、色はフッターでは白、会社概要では黒です。検索エンジン向けの会社情報（構造化データ）のロゴには `assets/img/noda-logo.png`（512×512）を使っています。faviconとホーム画面アイコンは、もともと同じマークです。
- 導入店舗の帯の写真は、現行LPの帯画像から写真部分を切り出したもので解像度が低めです。元の写真があれば差し替えます。

## 実装メモ
